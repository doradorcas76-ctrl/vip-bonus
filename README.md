# 🎁 VIP Bonus Telegram Bot

Claim daily bonuses, earn loyalty points, and unlock exclusive VIP perks — all inside Telegram.
Non-gambling. Community-friendly. Deployed via GitHub + Railway.

## Features
- Daily bonus rewards
- VIP tier progression (Starter → Platinum)
- Perks viewer
- 24/7 uptime on Railway

## Deploy on Railway
1. Push this repo to GitHub.
2. Railway → **New Project** → **Deploy from GitHub**.
3. Add variable: `BOT_TOKEN=your_token`.
4. Deploy 🚀

## Local Run
```bash
pip install -r requirements.txt
export BOT_TOKEN=your_token
python bot.py
```
